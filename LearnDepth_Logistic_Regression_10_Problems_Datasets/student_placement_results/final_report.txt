STUDENT PLACEMENT ELIGIBILITY USING LOGISTIC REGRESSION
======================================================================

1. PROBLEM STATEMENT
----------------------------------------------------------------------
Predict whether a student is likely to meet a placement eligibility criterion using Logistic Regression.

2. DATASET DESCRIPTION
----------------------------------------------------------------------
Number of records: 1000
Number of features: 6
Target variable: target

Features:
- cgpa
- attendance_pct
- coding_score
- projects_completed
- internship_months
- backlogs

3. DATA QUALITY
----------------------------------------------------------------------
Missing values: 0
Duplicate rows: 0

4. PREPROCESSING
----------------------------------------------------------------------
All input features are numerical. StandardScaler was used to standardize the feature values before Logistic Regression.
The preprocessing and model were combined using a Scikit-learn Pipeline to prevent data leakage.

5. TRAIN / TEST SPLIT
----------------------------------------------------------------------
80% training data and 20% testing data.
Random state: 42
Stratified split: Yes

6. MODEL
----------------------------------------------------------------------
Algorithm: Logistic Regression
Maximum iterations: 1000

10. LIMITATIONS
----------------------------------------------------------------------
The dataset is synthetic and intended for educational practice. Therefore, model performance may not represent performance on real-world student placement data. Real-world deployment would require validation using representative data, additional feature analysis, fairness checks, and monitoring.

11. CONCLUSION
----------------------------------------------------------------------
A Logistic Regression classifier was developed to predict student placement eligibility. The model was evaluated using accuracy, precision, recall, F1 score, ROC-AUC and a confusion matrix. The results provide an educational demonstration of binary classification using Logistic Regression.
